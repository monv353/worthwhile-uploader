Privacy policy

Last updated: 7 November 2026

Worthwhile Uploader ("the app") is a private command-line tool operated by the owner of the YouTube channel Worthwhile (@worthwhilechannel). It has a single user: the channel owner.

What the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos and thumbnails to the owner's own channel and set their titles, descriptions and publishing schedule;
  • read the owner's own channel and video information and its analytics, to report on the channel's performance.

The app does not access any other person's data, and it does not collect data from viewers.

How data is stored and shared

  • The OAuth access token is stored only on the owner's own computers and is never shared.
  • Channel statistics are kept only in the owner's private files for reporting.
  • No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are subject to the YouTube Terms of Service and the Google Privacy Policy.
